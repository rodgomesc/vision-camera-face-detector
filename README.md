# vision-camera-face-detector

VisionCamera Frame Processor Plugin to detect faces and facial landmarks

## Installation

```sh
git clone --recurse-submodules -b v2 https://github.com/rodgomesc/vision-camera-face-detector.git

cd vision-camera-face-detector

yarn install
```

## Usage

```js
import { multiply } from 'vision-camera-face-detector';

// ...

const result = await multiply(3, 7);
```
